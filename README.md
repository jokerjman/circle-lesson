## โครงสร้างบทเรียน

- 4 ส่วนบทเรียน ปลดล็อกทีละส่วน: ส่วนต่าง ๆ ของวงกลม · มุมในครึ่งวงกลมและมุมที่จุดศูนย์กลาง · ส่วนโค้งเดียวกันและสี่เหลี่ยมแนบในวงกลม · คอร์ดและเส้นสัมผัส
- แบบทดสอบย่อย สุ่ม 5 ข้อจากคลังส่วนละ 14 ข้อ (เกณฑ์ผ่าน 60%) และแบบทดสอบประมวล สุ่ม 10 ข้อจาก 20 ข้อ (เกณฑ์ผ่าน 70%)
- กิจกรรมโต้ตอบ: เครื่องสุ่มโจทย์หาค่า x จากรูปวงกลม (คำนวณมุมจากพิกัดจริง) การ์ดพลิกทบทวน จับคู่ จำแนก เรียงลำดับ
- การ์ดสรุปบทเรียน และเกียรติบัตร (โทนทางการ พิมพ์ได้)
- ข้อมูลนักเรียนเก็บในเบราว์เซอร์ของผู้เรียน (localStorage, key `circle3_db_v1`) — ใช้ชื่อ ชั้น เลขที่เดิมเพื่อเรียนต่อ
- ระบบผู้ดูแล: ดูผลการเรียนรายคน ส่งออก CSV ตั้งค่ารายวิชาและเกณฑ์ผ่าน
